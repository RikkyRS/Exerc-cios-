🔹 Parte 3 – Misturando Arrays + Hashes

1 - Lista de alunos com notas
Crie um array de hashes, onde cada hash representa um aluno:

> { nome: "Ana", nota: 8.5 }

Peça ao usuário para cadastrar 3 alunos (nome e nota).
Depois:

> Mostre a média das notas da turma
> Mostre o nome do aluno com a maior nota

2 - Carrinho de compras
Use um array de hashes para representar itens de um carrinho:

> { nome: "Arroz", preco: 10.0, quantidade: 2 }

Peça ao usuário para adicionar alguns itens.
Depois calcule e mostre:

> O total a pagar (somando preco * quantidade de cada item)

3 - Agenda de contatos
Crie um array de hashes onde cada contato tem:

> { nome: "João", telefone: "9999-9999" }


Peça para o usuário cadastrar alguns contatos.
Depois:

> Peça um nome e procure na lista
> Se encontrar, mostre o telefone
> Se não, mostre uma mensagem falando que não encontrou
